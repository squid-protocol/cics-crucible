# cics-crucible

An adversarial benchmark of small, original CICS COBOL programs (with their BMS maps, CSD
definitions and copybooks), each shipping a hand-written expected event log derived from IBM
CICS documentation. It is the oracle for GitGalaxy's CICS-to-Java translation
([squid-protocol/gitgalaxy#3989](https://github.com/squid-protocol/gitgalaxy/issues/3989)).
